# 🛒 쇼핑몰 홈페이지 테스트용 더미 데이터 세트 (v1.0)

본 문서는 쇼핑몰 홈페이지 구축 및 기능 테스트(프론트엔드 UI 렌더링, 백엔드 DB 연동 등)를 위해 작성된 상품 및 가상 농가 더미 데이터입니다. 현실감 있는 테스트 환경을 위해 실제 시장 시세와 기준표를 엄격하게 반영했습니다.

---

## 1. 데이터 산출 근거 (가격 및 당도)

### 💰 가격 선정 근거 (2026년 11월 실거래가 기반)
단순 추정을 배제하고, 현재 시점의 온/오프라인 시장 데이터와 가락시장 도매가를 조사하여 현실적인 평균가를 적용했습니다.

*   **가공식품 3종 (배즙, 매실청, 포도즙):** 현재 온라인 쇼핑몰에서 실제로 판매되고 있는 유사 용량/성분 제품들의 소비자 실거래가 평균을 적용.
    *   **배즙 (50포):** 시중가 2.5만~4만 원 선 ➔ **32,000원**
    *   **매실청 (1.2L):** 시중 1L 기준가 환산 ➔ **12,500원**
    *   **포도즙 (1L):** 수제/유기농 제품 실거래가 ➔ **11,000원**
*   **신선농산물 6종 (사과, 배, 복숭아, 고구마, 감자, 당근):** KAMIS(농산물유통정보) 및 가락시장 당일 경매가(상~특 등급)를 해당 중량으로 환산한 뒤, 온/오프라인 시중 소비자가를 더해 **도소매 평균가**로 책정.

### 🍎 당도(Brix) 적용 기준 (프리미엄 등급)
농산물 품목 기준표상 **'당도 표시 여부: O'**에 해당하는 과일류(사과, 배, 복숭아)에 한하여, '특상품' 기준의 프리미엄 당도를 적용했습니다. (*채소류는 당도 표시 UI 조건부 렌더링(숨김) 테스트를 위해 빈칸 처리함*)

*   **사과 (부사):** **16.0Bx** (특상급 고당도 꿀사과 기준)
*   **배 (신고):** **14.5Bx** (신고배 중 최고 수준의 단맛)
*   **복숭아 (황도):** **15.5Bx** (최상급 고당도 황도 기준)
