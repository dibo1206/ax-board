1. 홈 화면 — 상품 목록
상단 헤더에는 홈페이지 이름과 [홈], [상품 추천받기] 메뉴를 배치한다.
본문 상단에는 “내 취향에 맞는 농산물을 찾아보세요”라는 안내 문구와 [입맛에 맞는 상품 추천받기] 버튼을 배치한다.
상품 목록 영역에는 상품 카드를 세로로 나열한다. 각 카드에는 상품 사진, 상품명, 가격, 판매 단위, 1개당 무게, 품절 여부를 표시한다. 상품 카드를 누르면 해당 상품의 상세 화면으로 이동한다.
화면 오른쪽 아래에는 [상담하기] 버튼을 고정하여 배치한다. 버튼을 누르면 상담 챗봇 창이 열린다.
2. 상품 상세 화면
상단 헤더에는 [뒤로 가기] 버튼과 상품명을 표시한다.
본문에는 상품 사진, 상품명, 가격, 판매 단위, 1개당 무게, 박스당 개수, 주요 특징, 당도 정보가 있는 경우 당도를 순서대로 배치한다. 그 아래에는 보관 방법과 배송 안내 영역을 배치한다.
하단에는 [주문 문의]와 [이 상품 물어보기] 버튼을 배치한다. [주문 문의]를 누르면 이름, 연락처, 수량을 입력하는 문의 폼이 열린다. [이 상품 물어보기]를 누르면 해당 상품에 관해 질문할 수 있는 상담 챗봇이 열린다.
품절 상품은 상품명 옆에 “품절”을 표시하고, 주문 문의 영역에도 품절 상태를 안내한다.
3. 생산자 상품 관리 화면
상단 헤더에는 “상품 관리” 제목과 [상품 등록] 버튼을 배치한다.
본문에는 생산자가 등록한 상품 목록을 배치한다. 각 항목에는 상품 사진, 상품명, 가격, 품절 상태와 [수정] 버튼을 표시한다.
[상품 등록]을 누르면 상품 등록 화면으로 이동한다. [수정]을 누르면 기존 정보가 입력된 수정 화면이 열리며, 가격과 품절 여부를 변경할 수 있다.
등록이나 수정이 완료되면 관리 목록과 소비자 화면에 변경된 정보를 반영한다.
4. 생산자 상품 등록 화면
상단 헤더에는 [뒤로 가기] 버튼과 “상품 등록” 제목을 배치한다.
입력 폼 영역에는 상품명, 가격, 판매 단위, 1개당 무게, 박스당 개수, 상품 사진, 주요 특징, 보관 방법, 품절 여부를 입력하는 항목을 배치한다. 당도는 정보가 있는 경우 입력할 수 있도록 선택 항목으로 둔다.
화면 하단에는 [등록 취소], [임시 저장], [등록 확인] 버튼을 배치한다.
[등록 취소]를 누르면 입력 내용을 상품 목록에 반영하지 않고 상품 관리 화면으로 돌아간다. [임시 저장]을 누르면 작성 중인 내용을 저장하고 “임시 저장되었습니다”라는 안내를 표시한다. 임시 저장한 상품은 소비자 화면에 노출되지 않는다.
[등록 확인]을 누르면 필수 입력 항목을 확인한다. 누락된 항목이 있으면 해당 입력란 아래에 안내를 표시한다. 정상적으로 등록되면 “상품이 등록되었습니다”라는 안내를 표시하고, 생산자 관리 목록에 상품을 추가한다. 소비자 홈의 상품 개수와 목록에도 반영한다.
5. 소비자 맞춤형 추천 화면
상단에는 “맞춤 상품 추천” 제목과 [닫기] 버튼을 배치한다. 제목 아래에는 “1/4”와 같이 현재 질문의 진행 상태를 표시한다.
질문 영역에는 구매 목적, 예산, 맛 선호도, 상품 유형에 관한 질문을 한 화면에 하나씩 표시한다. 각 질문 아래에는 선택지 버튼을 배치한다.
구매 목적은 선물용 또는 가정용, 예산은 가격대, 맛 선호도는 달콤한 맛 또는 새콤한 맛, 상품 유형은 농산물 또는 가공식품 등으로 선택할 수 있게 한다.
하단에는 [이전]과 [다음] 버튼을 배치한다. 마지막 질문에서는 [다음] 대신 [추천 결과 보기] 버튼을 표시한다.
6. 추천 결과 및 상품 비교 화면
상단에는 “추천 결과” 제목을 표시하고, 그 아래에 소비자가 선택한 구매 목적, 예산, 맛 선호도, 상품 유형을 요약한다.
본문에는 추천 상품 카드를 최대 3개 배치한다. 각 카드에는 상품 사진, 상품명, 가격, 주요 특징, 추천 이유와 [상세 보기] 버튼을 표시한다. 추천 이유는 등록된 정보와 소비자의 응답을 근거로 작성한다.
각 카드에는 비교할 상품을 선택하는 항목을 배치한다. 상품을 2개 이상 선택하고 [선택 상품 비교하기]를 누르면 가격, 판매 단위, 무게, 주요 특징, 보관 방법을 나란히 확인할 수 있는 비교 영역이 열린다.
조건에 맞는 상품이 없으면 “조건을 하나 바꿔 보세요”라는 안내와 [조건 변경하기] 버튼을 표시한다. 가까운 조건의 상품이 있으면 어떤 조건이 일치하지 않는지 함께 표시한다.
화면 하단에는 [다시 추천받기] 버튼을 배치한다.
7. 상담 챗봇 창
홈과 상품 상세 화면의 오른쪽 아래에서 열리는 채팅창으로 구성한다.
채팅창 상단에는 “상품 상담” 제목과 [닫기] 버튼을 배치한다. 본문에는 대화 내용과 함께 [상품 추천], [상품 비교], [상품 문의] 선택 버튼을 표시한다.
하단에는 질문 입력란과 [보내기] 버튼을 배치한다. 소비자는 상품 특징, 가격, 보관 방법, 배송 및 구매 방법을 자유롭게 질문할 수 있다.
답변 아래에는 “근거: 상품 정보 / 보관 안내”와 같이 참고한 출처를 표시한다. 확인할 수 있는 정보가 없으면 안내 문구와 [전화 문의], [카카오톡 문의] 버튼을 표시한다.
8. 관리자 회원 관리 화면
상단 헤더에는 “회원 관리” 제목을 배치한다.
본문 상단에는 아이디 검색창, 회원 유형 필터, 이용 상태 필터와 [회원 추가] 버튼을 배치한다.
회원 목록에는 아이디, 회원 유형인 생산자·소비자, 이용 상태와 [상세 보기], [수정], [삭제] 버튼을 표시한다.
[상세 보기]를 누르면 회원 정보와 연결된 문의 내역을 확인할 수 있다. [수정]을 누르면 회원 유형과 이용 상태 등을 변경하는 폼이 열린다. 저장하면 관리 화면에 변경된 정보를 반영한다.
[삭제]를 누르면 삭제 확인 창을 표시한다. [취소]를 누르면 기존 정보를 유지하고, [삭제 확인]을 누르면 해당 회원을 목록에서 삭제한다.
회원가입과 로그인 기능은 제외하므로, 이 화면에서 관리할 회원 정보는 관리자가 직접 등록하는 방식으로 구성한다. 결제 기능이 없으므로 주문정보 영역은 구매가 완료된 주문 대신 주문 문의 내역으로 구성한다.
